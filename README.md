# ♻️ RECRECAR

Página educativa e interactiva sobre reciclaje en Sincelejo, Sucre (Colombia).

## ¿Qué incluye?
- Guía de separación de residuos con los colores usados en Colombia.
- Animaciones y diseño adaptable a móviles.
- Mapa centrado en Sincelejo y enlaces de búsqueda en Google Maps para organizaciones locales.
- Minijuego de 5 preguntas.
- Consejos para reducir y reutilizar residuos.

> **Aviso:** Los establecimientos se presentan como referencias para consultar. Antes de visitarlos, verifica sus direcciones, horarios, materiales aceptados y si reciben entregas del público. El mapa no atribuye coordenadas exactas sin verificar.

## Abrir localmente
Abre `index.html` en un navegador. No se requiere servidor ni base de datos. Para el mapa y las fuentes hace falta internet.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `RECRECAR`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` **a la raíz del repositorio** (no dentro de otra carpeta).
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guarda.
5. La dirección será `https://TU_USUARIO.github.io/RECRECAR/` cuando termine la publicación.

Tecnologías: HTML, CSS, JavaScript y Leaflet/OpenStreetMap.
